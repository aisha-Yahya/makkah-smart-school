# منصة مدارس مكة الأهلية الحديثة الذكية
### Makkah Modern Smart Schools Platform — Qahzah Branch (Ibb, Yemen)

منصة تعليمية وإدارية ذكية متكاملة مصممة خصيصاً لـ **مدارس مكة الأهلية الحديثة (فرع قحزة)**، تشمل بوابات تفاعلية متطورة للطلاب والمعلمين وإدارة الكنترول المدرسي، مع تكامل كامل مع نظام المدرسة المكتبي (School Pro).

---

## 🏛️ البوابات والأنظمة الرئيسية

### 1. بوابة المعلم الذكية (Teacher Portal)
* **تحضير وتصوير الدروس اليومية بالذكاء الاصطناعي:** رفع صور صفحات الدرس وتوليد خطط تحضير 45 دقيقة تلقائياً.
* **شات المعلم البيداغوجي المتقدم:** مساعد ذكي لمعالجة المفاهيم الصعبة وصياغة الأسئلة ومراعاة الفروق الفردية.
* **أرشيف الدروس المحضرة والمصورة:** حفظ دائم لكافة الدروس السابقة واستعراضها بضغطة زر.
* **الألعاب الصفية التفاعلية (5 ألعاب متزامنة):**
  1. عجلة الحظ 🎡 (سحب عشوائي وتحديات صفية).
  2. تحدي 20 ثانية ⏱️ (سباق سرعة البديهة والوقت).
  3. صناديق الحظ ثلاثية الأبعاد 🎁 (مفاجآت وجوائز وتشويق).
  4. بنك الاختبارات الذكي 📝 (توليد وتنسيق الاختبارات الشهرية وطباعتها على صفحة أو صفحتين A4 أو تصديرها إلى Word).
  5. كشف التقييم والمشاركة الشفهية ⭐ (رصد درجات المشاركة والتميز المباشر).

### 2. بوابة الطالب الذكية (Student Portal)
* **المعلم الذكي الخاص بالطالب:** مناقشة وشرح أي درس خطوة بخطوة بالذكاء الاصطناعي مع إمكانية تصوير وحل المسائل الصعبة.
* **مكتبة المناهج والكتب المدرسية:** استعراض الفهارس والوحدات الدراسية المعتمدة لجميع المراحل.
* **كشف الدرجات والنتائج:** استعراض نتائج أعمال السنة والامتحانات الشهرية والنهائية المزامنة من الكنترول.
* **السجل المالي للرسوم:** متابعة الأقساط والرسوم الدراسية والمبالغ المتبقية وسندات القبض.

### 3. بوابة الإدارة والكنترول (Control & Admin Portal)
* **إدارة الطلاب:** البحث، التصفية حسب الشعبة والحالة (نشط / موقف)، وإدارة بيانات الطلاب الرسمية.
* **إدارة المعلمين:** استعراض الكادر التعليمي لعام 2026-2027، المواد المسندة، والبيانات الإدارية.
* **طباعة بطاقات الهوية المدرسية الذكية:** تصميم بطاقات تعريفية للطلاب مع باركود وشعار المدرسة بجودة عالية جاهزة للطباعة.
* **كشف المراجعة الشامل للشفوي:** تدقيق وتقييم درجات الشفوي والأنشطة الشهرية لجميع الصفوف وتصديرها بصيغة CSV.

## ⚙️ البنية التقنية (Architecture)

* **الواجهة الأمامية (Frontend):** 
  * HTML5, Modern Vanilla JavaScript (ES6+), Tailwind CSS, Lucide Icons.
  * تصميم انسيابي فائق السرعة يعمل بالكامل بنظام Single Page Application متجاوب مع جميع الشاشات.
  * دعم كامل للعمل الأوفلاين (Offline-First) والاتصال المباشر.

* **الواجهة الخلفية (Backend API):**
  * RESTful PHP API داخل مجلد `api/` للتعامل مع قواعد البيانات والمزامنة.
  * قاعدة بيانات SQLite محلية مدمجة وسريعة (`api/data/school_pro_synced.sqlite`).

* **أداة المزامنة المكتبية (School Pro Desktop Sync Tool):**
  * برنامج بايثون مستقل داخل مجلد `school_pro_sync_tool/` لقراءة بيانات سكول برو (SQL Server / Access) ومزامنتها لحظياً إلى قاعدة بيانات المنصة وسحابة المدرسة.

## 🚀 كيفية تشغيل المشروع محلياً

### الطريقة الأولى: عبر مشغل المنصة المباشر
اضغط نقراً مزدوجاً على ملف:
```cmd
start_platform.bat
```
أو عبر PowerShell:
```powershell
.\run_platform.ps1
```

### الطريقة الثانية: عبر خادم PHP محلي
قم بتشغيل الخادم من المجلد الرئيسي للمشروع:
```bash
php -S localhost:8000
```
ثم افتح المتصفح على: `http://localhost:8000`

## 🔒 الأمان وحقوق الملكية
* اسم وشعار **مدارس مكة الأهلية الحديثة — فرع قحزة** محمي نظامياً وبرمجياً في كافة مخرجات المنصة ووثائقها الرسمية.
* الصلاحيات الإدارية (إضافة وحذف الطلاب والمعلمين وتعديل الشعب) محصورة حصراً بإدارة الكنترول المدرسي.
* تطوير وبرمجة المنصة: **المهندسة / عائشة يحيى الزقري**.
* مدير المدرسة: **الأستاذ الفاضل / يحيى علي أحمد الزقري**.
